# RobloxPingEmulator
**RobloxPingEmulator** is a tool that uses **NtReadVirtualMemory** to read the current server's IP address from Roblox's internals then uses a mathematical formula created by a Linear Regression model trained with **~500 examples** to estimate the latency between your device and Roblox's servers.
# Offsets
For each roblox version you need to update offsets.
You can get updated offsets at **https://offsets.imtheo.lol/offsets.hpp**.
